Harmoniq: AI Study Tool | JavaScript, HTML, CSS, DeepSeek API, Claude API, Vercel

* Web-based study tool for learners who get overwhelmed, using AI-assisted development, 
that generates study material in a simpler, more manageable form.

* Integrated two LLM APIs (DeepSeek and Claude) for content generation,
with API calls handled through a Vercel serverless function.

* Designed the interface, including a dark mode and a feedback form, and deployed
it to Vercel as a working MVP.
